Spot Signals Setting

Every field below is edited in place — change Strategy and it saves automatically as soon as you click away (no separate Save button); the Auto-Trade checkbox takes effect the moment you tick it. "Trade Demo"/"Trade Real" load that symbol into the header and jump straight to the matching order form. 🎯 Auto-Select hands the Strategy column to the AI: it periodically backtests every built-in strategy for that asset and keeps the top few by win rate, trading only when a majority of them agree — see the Strategy cell's tooltip for which ones are currently selected. Backtested win rate reflects each strategy's technical performance only (historical fundamentals aren't available for backtesting), even though live trades still use each selected strategy's real technical+fundamental weighting. Price/24h % are live reference data (same feed as the Market Data card), refreshed each time this list loads — not used by the strategy/auto-trade logic itself.

Futures Signals Setting — Real & AI Auto-Trade

Unlock Real Trading from the Real Trading tab first to manage this Signals Setting.

Fully independent from the Demo Futures Signals Setting above — a symbol here is its own separate entry, with its own leverage/strategy/auto-trade setting. 🤖 Auto-trade here is a deliberate, higher-friction opt-in: even when ticked, it does nothing unless the server operator has ALSO set ENABLE_FUTURES_AUTO_TRADING=true in .env and restarted the server. When fully active, it places real, leveraged, unattended trades with liquidation risk on a timer, with leverage capped at a server-configured maximum. There is deliberately no "enable for all" bulk button here — each symbol is a conscious, one-at-a-time decision.
